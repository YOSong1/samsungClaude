# Case 04. 예시 페이지를 복제하는 템플릿

## 학습 목표

예시 슬라이드와 실제 객체를 연결하고 복제 방식을 설계한다.

## 개념 설명

템플릿2는 마스터 1개·레이아웃 3개이며 2~8장이 같은 레이아웃이다. 형식은 실제 페이지에 있으므로 복제 후 입력 영역을 교체한다. 6장은 독립 그림 3개, 8장은 합성 그림 1개다. 4장은 동영상·자막, 9장은 링크가 있다. 제목·본문 이름만으로 객체를 결정하지 않는다.

## 파일 안내

- 실제 지침: [company-ppt-library/SKILL.md](company-ppt-library/SKILL.md)
- 템플릿 원본 복사본: [company-ppt-library/assets](company-ppt-library/assets)
- 업로드용 패키지: [company-ppt-library.zip](company-ppt-library.zip)
- 이 케이스만 보고 따라 하는 절차: [등록_및_활용.md](등록_및_활용.md)
- 네 케이스 한눈에 보기: [Claude_PPT_skill_4케이스_안내.pptx](../Claude_PPT_skill_4케이스_안내.pptx)
- 공통 등록 설명: [등록·사용 가이드](../00_강의자료/등록_사용_가이드.md)

이 skill은 대화에서 설명한 설계를 실제 파일로 정리한 교육용 버전이다. 제공 템플릿은 사용자 원본의 바이트 동일 복사본이다. 실제 Claude 계정 설치와 Claude에서의 PPT 생성 성공 여부는 아직 검증하지 않았다.

## 실습 순서

1. SKILL.md를 열어 설명과 작업 범위를 읽는다.
2. assets의 PPT를 열어 레이아웃과 실제 슬라이드를 비교한다.
3. 해당 ZIP 하나를 등록하고 정확한 skill 이름으로 요청한다.
4. 아래 프롬프트를 입력한다.
5. 기대 동작과 비교한다. 구성안을 수정하고 원하면 PPT 제작을 요청한다.

```text
company-ppt-library skill을 사용해 신입사원 시스템 안내를 구성해줘. 원본 2장의 설명+이미지, 3장의 4단계, 6장의 3개 이미지 구성을 활용해 총 3장 구성안을 작성해줘. 각 입력 영역에 필요한 자료와 없는 자료를 표시해줘.
```

## 해설과 평가

결과물 3장과 원본 슬라이드 번호를 구분해야 한다. 6장의 원문 2·3번은 이어지는 문장이므로 독립 사례로 바꿀 때 재작성한다. 8장을 세 개 이미지 슬롯으로 선택하면 안 된다.

평가 항목: 사용자 범위 준수, 올바른 파일 선택, 페이지 구조 일치, 근거 없는 정보 미생성, 실제 파일 제공 여부, 미검증 항목의 정직한 보고.

## 확장 과제

한글 제목을 길게 바꾸고 항목 수를 하나 늘려본다. 텍스트 축소만으로 처리하는지, 요약·재배치·페이지 변경 등 의미를 유지하는 대안을 선택하는지 살핀다. 고정 장수 조건을 추가하여 다시 비교한다.
