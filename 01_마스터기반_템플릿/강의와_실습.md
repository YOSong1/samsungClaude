# Case 01. 마스터가 갖춰진 템플릿

## 학습 목표

원본 마스터와 레이아웃을 구분하고 3장 구성안을 만든다.

## 개념 설명

마스터는 공통 서식, 레이아웃은 페이지 배치, 실제 슬라이드는 내용이다. 템플릿1은 마스터 1개·레이아웃 15개·예시 12장이다. "제목 및 내용"만 선택하는 것보다 내용 관계에 맞춰 비교·3 열·사진 레이아웃을 선택해야 한다. 표·차트 예시는 실제 슬라이드의 객체일 수 있으므로 레이아웃 선택만으로 재현된다고 생각하지 않는다.

## 파일 안내

- 실제 지침: [company-ppt-master/SKILL.md](company-ppt-master/SKILL.md)
- 템플릿 원본 복사본: [company-ppt-master/assets](company-ppt-master/assets)
- 업로드용 패키지: [company-ppt-master.zip](company-ppt-master.zip)
- 이 케이스만 보고 따라 하는 절차: [등록_및_활용.md](등록_및_활용.md)
- 네 케이스 한눈에 보기: [Claude_PPT_skill_4케이스_안내.pptx](../Claude_PPT_skill_4케이스_안내.pptx)
- 공통 등록 설명: [등록·사용 가이드](../00_강의자료/등록_사용_가이드.md)

이 skill은 대화에서 설명한 설계를 실제 파일로 정리한 교육용 버전이다. 제공 템플릿은 사용자 원본의 바이트 동일 복사본이다. 실제 Claude 계정 설치와 Claude에서의 PPT 생성 성공 여부는 아직 검증하지 않았다.

## 실습 순서

1. SKILL.md를 열어 설명과 작업 범위를 읽는다.
2. assets의 PPT를 열어 레이아웃과 실제 슬라이드를 비교한다.
3. 해당 ZIP 하나를 등록하고 정확한 skill 이름으로 요청한다.
4. 아래 프롬프트를 입력한다.
5. 기대 동작과 비교한다. 구성안을 수정하고 원하면 PPT 제작을 요청한다.

```text
company-ppt-master skill을 사용해 ‘신입사원 온보딩 개선’ 구성안을 총 3장으로 정리해줘. 표지, 현행과 개선안 비교, 세 가지 실행 과제로 구성하고 발표템플릿1의 레이아웃을 지정해줘. 이번에는 구성안만 작성해줘.
```

## 해설과 평가

표지=제목 슬라이드, 비교=비교, 실행 과제=3 열이 합리적인 예다. 단, 실제 내용이 세 가지 독립 항목인지 확인한다. 마스터가 존재하는 것과 서식 상속이 정상인 것을 구분한다.

평가 항목: 사용자 범위 준수, 올바른 파일 선택, 페이지 구조 일치, 근거 없는 정보 미생성, 실제 파일 제공 여부, 미검증 항목의 정직한 보고.

## 확장 과제

한글 제목을 길게 바꾸고 항목 수를 하나 늘려본다. 텍스트 축소만으로 처리하는지, 요약·재배치·페이지 변경 등 의미를 유지하는 대안을 선택하는지 살핀다. 고정 장수 조건을 추가하여 다시 비교한다.
