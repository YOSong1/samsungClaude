## 기본 템플릿과 레이아웃

기본 파일은 `assets/발표템플릿1.pptx`이다. `references/layout-catalog.md`를 읽고 내용의 관계에 맞는 레이아웃을 고른다. 선택 후 실제 파일의 레이아웃과 개체 틀을 확인한다.

원본은 12장, 마스터 1개, 레이아웃 15개다. 레이아웃별 개체 틀은 제목·본문·사진 등의 역할과 idx로 구분하되 배열 순서에 의존하지 않는다. 템플릿의 다른 버전이나 다른 파일에서는 재분석한다.

슬라이드를 해당 레이아웃에 연결해 기존 개체 틀을 채운다. 필요한 예시 표·차트가 실제 슬라이드에만 존재하면 해당 요소를 보존하는 복제·편집 방법을 사용한다. 레이아웃을 선택하면 모든 예시 콘텐츠가 생긴다고 가정하지 않는다.

검증 시 마스터·레이아웃의 존재와 슬라이드의 연결을 확인한다. 직접 서식이 상속을 덮어쓸 수 있으므로 마스터가 존재한다는 사실만으로 전체 서식 상속이 정상이라고 판단하지 않는다.
