# 템플릿 선택 카탈로그

| ID | 실제 파일 | 처리 방식 | 우선 고려할 상황 |
|---|---|---|---|
| template1 | assets/발표템플릿1.pptx | master-layout | 일반 발표, 비교, 본문, 여러 열과 사진 배치 |
| template2 | assets/발표템플릿2.pptx | slide-library | 사용법, 단계 설명, 화면 중심 교육 |

이 용도는 실습을 위한 선택 기준이며 회사 공식 승인 분류가 아니다. 실제 업무 정책이 주어지면 반영한다. 내부 보고·고객 제안·교육용이라는 세 개의 가상 PPT는 제공하지 않는다. 제공된 실제 파일 두 개로 실습한다.

사용자가 파일을 지정하면 그대로 사용한다. 템플릿을 지정하지 않았고 목적만으로 구분할 수 있으면 선택 이유를 알리고 진행한다. 특정 형식이 부족하면 이를 설명하고 필요한 페이지 보완안을 제시한다.
