# Case 03. 여러 템플릿의 통합 선택

## 학습 목표

디자인 차이와 업무 절차 차이를 구분하고 템플릿을 선택한다.

## 개념 설명

디자인·레이아웃 차이는 공통 skill과 템플릿별 안내로 관리한다. 요구사항 수집·필수 항목·검토 절차가 크게 다른 업무는 skill 분리를 고려한다. 이 패키지는 실제 파일 두 개를 template1과 template2로 등록했다. 용도는 실습용 권장값이고 회사 공식 정책이 아니다.

## 파일 안내

- 실제 지침: [company-ppt-router/SKILL.md](company-ppt-router/SKILL.md)
- 템플릿 원본 복사본: [company-ppt-router/assets](company-ppt-router/assets)
- 업로드용 패키지: [company-ppt-router.zip](company-ppt-router.zip)
- 이 케이스만 보고 따라 하는 절차: [등록_및_활용.md](등록_및_활용.md)
- 네 케이스 한눈에 보기: [Claude_PPT_skill_4케이스_안내.pptx](../Claude_PPT_skill_4케이스_안내.pptx)
- 공통 등록 설명: [등록·사용 가이드](../00_강의자료/등록_사용_가이드.md)

이 skill은 대화에서 설명한 설계를 실제 파일로 정리한 교육용 버전이다. 제공 템플릿은 사용자 원본의 바이트 동일 복사본이다. 실제 Claude 계정 설치와 Claude에서의 PPT 생성 성공 여부는 아직 검증하지 않았다.

## 실습 순서

1. SKILL.md를 열어 설명과 작업 범위를 읽는다.
2. assets의 PPT를 열어 레이아웃과 실제 슬라이드를 비교한다.
3. 해당 ZIP 하나를 등록하고 정확한 skill 이름으로 요청한다.
4. 아래 프롬프트를 입력한다.
5. 기대 동작과 비교한다. 구성안을 수정하고 원하면 PPT 제작을 요청한다.

```text
company-ppt-router skill을 사용해 ‘신입사원 사내 시스템 사용법’을 구성해줘. 화면과 단계 설명 중심이므로 등록된 템플릿 중 적합한 것을 선택하고 이유를 알려줘. 6장 구성안만 먼저 제시해줘.
```

## 해설과 평가

단계·화면 중심에는 template2를 고려할 수 있다. 사용자가 template1을 지정하면 그 선택을 우선한다. 비용 비교표가 필요하지만 적합한 원본 페이지가 없으면 새 유형 필요성을 설명한다.

평가 항목: 사용자 범위 준수, 올바른 파일 선택, 페이지 구조 일치, 근거 없는 정보 미생성, 실제 파일 제공 여부, 미검증 항목의 정직한 보고.

## 확장 과제

한글 제목을 길게 바꾸고 항목 수를 하나 늘려본다. 텍스트 축소만으로 처리하는지, 요약·재배치·페이지 변경 등 의미를 유지하는 대안을 선택하는지 살핀다. 고정 장수 조건을 추가하여 다시 비교한다.
