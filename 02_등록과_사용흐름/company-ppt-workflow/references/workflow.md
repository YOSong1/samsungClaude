# 사용자 관점의 단계별 요청

## 1. 내용·구성 정리

```text
company-ppt-workflow skill을 사용해줘.
주제는 사내 생성형 AI 시범 도입 방안, 청중은 임원과 부서장,
목적은 3개월 시범 도입 추진 여부 결정이야.
표지 포함 총 8장, 발표 10분으로 구성해줘.
첨부한 내부 메모만 근거로 쓰고 없는 비용·효과 수치는 만들지 마.
이번에는 PPT 생성 없이 요구사항 요약과 슬라이드별 구성안을 보여줘.
```

## 2. 수정

```text
적용 업무는 회의록 작성, 사내 문서 검색, 보고서 초안으로 바꿔줘.
효과는 확정 수치 대신 시범 도입에서 측정할 지표로 설명해줘.
총 8장을 유지해줘.
```

## 3. 파일 제작

```text
이 대화에서 수정한 최신 구성안으로 편집 가능한 PPT를 만들어줘.
skill에 포함된 발표템플릿1.pptx를 사용하고 마스터와 레이아웃을 유지해줘.
표지 포함 총 8장으로 만들고 샘플 문구와 가짜 연락처를 남기지 마.
실제 최종 .pptx를 제공하고 확인하지 못한 기능이 있으면 알려줘.
```

현재 대화에 다른 템플릿을 첨부하면 그 파일을 우선하도록 명시할 수 있다. 다른 서비스·대화의 파일이 자동 전달되지는 않는다. 사용자에게 실습용 내부 메모를 작성하거나 첨부하도록 한다. 이 패키지는 실제 회사 데이터를 제공하지 않는다.

## 바로 제작하는 요청

목적·청중·장수·자료·템플릿을 함께 적고 "구성부터 PPT 제작까지 진행해줘"라고 요청한다. 검토를 원할 때만 구성안에서 멈추도록 한다.
