# Case 02 등록과 활용

이 문서 하나만 보고 Case 02를 끝까지 진행할 수 있다. 다른 케이스를 먼저 하지 않아도 된다.

- skill 이름: `company-ppt-workflow`
- 올릴 파일: `02_등록과_사용흐름/company-ppt-workflow.zip`
- 쓰는 템플릿: 발표템플릿1.pptx (Case 01과 같은 파일)

Case 01이 템플릿 구조를 다룬다면 이 케이스는 대화 흐름을 다룬다. 한 번에 끝내지 않고 구성안 → 수정 → 제작으로 나눠 요청하는 연습이다.

## 1. 준비

`company-ppt-workflow.zip`을 내려받아 압축을 한 번 열어 본다. 맨 위가 `company-ppt-workflow` 폴더이고 그 바로 아래에 `SKILL.md`가 있어야 한다.

```
company-ppt-workflow/
  SKILL.md
  assets/발표템플릿1.pptx
  references/layout-catalog.md
  references/workflow.md
  references/template-inventory.json
  scripts/inspect_pptx.py
```

`references/workflow.md`에 3단계 요청 예시가 그대로 들어 있다. 실습 중에 열어 두면 편하다.

## 2. 실습 전에 만들어 둘 것

이 케이스는 "첨부한 내부 메모만 근거로 쓰라"는 요청을 연습한다. 패키지에는 회사 자료가 들어 있지 않으므로 메모를 직접 한 장 만든다. 실제 사내 문서를 쓸 필요는 없다. 아래 정도면 된다.

```text
[사내 메모] 생성형 AI 시범 도입 검토

- 대상 부서: 경영지원팀, 영업기획팀
- 검토 기간: 3개월
- 후보 업무: 회의록 정리, 사내 문서 검색, 보고서 초안
- 우려 사항: 사내 자료 반출, 결과 검수 인력
- 확정되지 않은 것: 도입 예산, 인당 절감 시간
```

마지막 줄을 일부러 넣는다. 없는 수치를 지어내는지 보는 장치다.

## 3. 등록하는 곳은 두 군데다

| 등록 위치 | 이걸 보는 것 |
|---|---|
| claude.ai 계정 | Claude 웹, 데스크톱 앱 |
| 내 PC의 파일 | Claude Code (터미널) |

웹과 데스크톱은 같은 계정 저장소를 본다. 한 번 올리면 둘 다에서 쓸 수 있고 따로 등록하지 않는다.

Claude Code는 저장소가 다르다. 다만 claude.ai 계정으로 로그인한 세션이면 계정 skill을 `~/.claude/skills/synced/` 아래로 자동으로 내려받는다. 이때는 아래 3-B를 따로 하지 않아도 된다. API 키나 환경변수로 인증했거나 조직 정책이 막아 둔 세션에서는 동기화가 되지 않으므로 3-B로 직접 설치한다.

3-A와 3-B를 둘 다 하면 같은 skill이 두 벌이 되어 어느 쪽이 걸릴지 갈린다. 하나만 한다. 계정에 올린 뒤 Claude Code에서 `/company-ppt-workflow`가 보이는지로 동기화 여부를 판단하면 된다.

## 3-A. Claude 웹·데스크톱에 등록

1. Customize → Skills → **+** → Create skill → **Upload a skill**
2. `company-ppt-workflow.zip`을 ZIP 그대로 올린다.
3. 목록에 생긴 `company-ppt-workflow`의 토글을 켠다.
4. Settings → Capabilities에서 **코드 실행**과 **파일 생성**을 켠다.

## 3-B. Claude Code에 설치

ZIP을 풀어 `company-ppt-workflow` 폴더를 통째로 복사한다.

- 계정 전체: `%USERPROFILE%\.claude\skills\company-ppt-workflow\`
- 프로젝트 한정: 그 프로젝트의 `.claude\skills\company-ppt-workflow\`

`...\skills\company-ppt-workflow\SKILL.md`가 되면 맞다.

## 4. 1단계 — 구성안만 받기

메모를 첨부하고 아래를 요청한다.

```text
company-ppt-workflow skill을 사용해줘.
주제는 사내 생성형 AI 시범 도입 방안, 청중은 임원과 부서장,
목적은 3개월 시범 도입 추진 여부 결정이야.
표지 포함 총 8장, 발표 10분으로 구성해줘.
첨부한 메모만 근거로 쓰고 없는 비용·효과 수치는 만들지 마.
이번에는 PPT 생성 없이 요구사항 요약과 슬라이드별 구성안을 보여줘.
```

여기서 볼 것은 두 가지다. 파일을 만들지 않고 구성안에서 멈추는가. 메모에 없는 예산과 절감 시간을 지어내지 않고 확인이 필요하다고 표시하는가.

## 5. 2단계 — 수정

```text
적용 업무는 회의록 작성, 사내 문서 검색, 보고서 초안으로 바꿔줘.
효과는 확정 수치 대신 시범 도입에서 측정할 지표로 설명해줘.
총 8장을 유지해줘.
```

항목을 바꾸면서 장수를 그대로 두라고 했을 때 어떻게 맞추는지 본다.

## 6. 3단계 — 제작

```text
이 대화에서 수정한 최신 구성안으로 편집 가능한 PPT를 만들어줘.
skill에 포함된 발표템플릿1.pptx를 사용하고 마스터와 레이아웃을 유지해줘.
표지 포함 총 8장으로 만들고 샘플 문구와 가짜 연락처를 남기지 마.
실제 최종 .pptx를 제공하고 확인하지 못한 기능이 있으면 알려줘.
```

## 7. 제대로 됐는지 확인

| 확인할 것 | 통과 기준 |
|---|---|
| 1단계 범위 | 구성안만 나오고 파일을 만들지 않았다 |
| 없는 수치 | 예산·절감 시간을 지어내지 않고 확인 필요로 뒀다 |
| 2단계 반영 | 결과물에 수정 전 업무 항목이 남아 있지 않다 |
| 장수 유지 | 수정 후에도 표지 포함 8장이다 |
| 3단계 결과 | 실제 .pptx 파일을 받았다 |
| 정직성 | 못 만들었으면 못 만들었다고 말한다 |

"이 대화에서 수정한 최신 구성안으로"라는 표현이 이 케이스의 연습 대상이다. 다른 대화에 있던 파일이나 내용이 자동으로 넘어오지는 않는다.

## 8. 이어서 해 볼 것

```text
같은 요청을 한 번에 해줘. 목적, 청중, 8장, 첨부 메모를 다 적을 테니
구성부터 PPT 제작까지 한 번에 진행해줘.
```

3단계로 나눴을 때와 한 번에 시켰을 때 결과가 어떻게 다른지 비교한다. 검토를 넣고 싶을 때만 구성안에서 멈추게 하면 된다는 것을 확인한다.

## 9. 막히면

| 증상 | 확인할 것 |
|---|---|
| Skills 메뉴가 없다 | 조직 정책과 내 역할 권한 |
| 업로드가 거부된다 | 압축 맨 위가 `company-ppt-workflow` 폴더인지 |
| 구성안만 시켰는데 파일을 만든다 | 요청에 "이번에는 생성 없이"가 들어갔는지 |
| 수정 전 내용이 남아 있다 | "이 대화에서 수정한 최신"을 명시했는지 |
| 메모를 못 읽는다 | 경로만 적지 말고 파일을 직접 첨부했는지 |
| PPT 파일이 안 나온다 | Settings → Capabilities의 코드 실행·파일 생성 |

## 10. 실습이 끝나면

`company-ppt-workflow` 토글을 끄고 다음 케이스로 넘어간다.

내 회사 템플릿에 같은 방식을 옮기는 요령은 `Claude_PPT_skill_4케이스_안내.pptx`의 팁 슬라이드에 정리해 두었다.
